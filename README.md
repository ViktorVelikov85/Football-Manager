# Football Manager System ⚽

Професионална десктоп система за управление на футболни клубове, играчи и шампионати, проектирана за лесна администрация на спортни бази данни.

## 🚀 Основни функции

* **Управление на клубове и каскадно изтриване**: Пълен CRUD цикъл за отбори с интелигентна защита при изтриване, която автоматично и безопасно почиства свързаните мачове, играчи и статистики.
* **Управление на състави**: Детайлна картотека на футболисти (позиция, номер, статус, рождена дата) и автоматично разделяне на имената при избор.
* **Интелигентно филтриране и търсене**: Динамично филтриране в реално време по име на играч, позиция и клуб директно през потребителския интерфейс.
* **Трансферен модул**: Следене на входящи и изходящи трансфери, трансферни суми и автоматизирана история на преминаванията между клубовете.
* **Модул за статистики и графики**: Визуализация на напреднали спортни анализи чрез динамично софтуерно изчертаване на графики (Топ голмайстори, картони и извършени фалове).
* **Строга бизнес валидация**: Защита в реално време срещу невалидни данни, дублиращи се имена на клубове и възрастови ограничения за играчи (минимум 14 години).

## 🛠 Технически спецификации

* **Технология**: C# Windows Forms (.NET)
* **Архитектура**: Трислойна архитектура (3-Tier Architecture) за строго разделение на логиката:
  * *Presentation Layer (UI)* – Потребителски интерфейс и контроли.
  * *Business Logic Layer (BLL)* – Услуги (Services) със специфични бизнес правила и валидации.
  * *Data Access Layer (DAL)* – Репозиторита (Repositories) за комуникация с базата данни.
* **База данни**: MySQL / MariaDB (с релационни връзки и ON DELETE CASCADE контроли).
* **UI контроли**: Ръчно конфигурирани DataGridView обекти, графично чертане чрез Graphics API (Paint събития) и вграден PlaceholderText.

## 🗄️ База данни
Проектът използва **MySQL / MariaDB**. За да подготвите средата:

1. Използвайте локален сървър (напр. **XAMPP**).
2. Стартирайте **Apache** и **MySQL** модулите от XAMPP Control Panel.
3. Отворете **phpMyAdmin** във вашия браузър.
4. Създайте нова база данни с име `football_manager`.
5. Импортирайте предоставения SQL дъмп файл (`football_manager.sql`).

## 🔗 Connection String
Настройката за връзка с базата данни се намира в Помощния клас `Db.cs` в DAL слоя:
`private static string connString = "server=localhost;database=football_manager;port=3306;uid=root;pwd=;charset=utf8;";`

## ⚡ Как се стартира

1. Отворете `.sln` файла на решението във **Visual Studio**.
2. Проверете дали пакетът `MySql.Data` е инсталиран правилно (възстановете NuGet пакетите, ако е необходимо).
3. Натиснете **F5** или бутона **Start**, за да компилирате и стартирате приложението.
